# BLK-031 — Cron du 09/10 : un compte en échec sur un 502 Spotify

| Friction | Cause réelle | Solution | Statut |
| -------- | ------------ | -------- | ------ |
| Le cron de 05:00 UTC répond 207 : un compte est mis à jour (56 titres), l'autre échoue et garde sa playlist de la veille | `fetchSpotifyWithRetry` ne retentait que les 429. Spotify a renvoyé un 502 passager (« Please try again later ») sur `PUT /playlists/{id}/followers`, premier appel de `createOrUpdatePlaylist` : l'erreur est remontée sans seconde tentative et a fait tomber tout le compte | Retry étendu aux statuts >= 500 (`isRetryable`) dans `spotify-http.ts` et sa copie Edge Function, même backoff, 3 tentatives ; test `spotify-http.test.ts` ; Edge Function redéployée (v17, correctif vérifié dans la source en production) ; playlist du compte régénérée à la main (53 titres). Commit `c1e6daf`. Non confirmé en conditions réelles : un 502 ne se provoque pas à la demande | résolu |
