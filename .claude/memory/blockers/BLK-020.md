# BLK-020 — Playlists lues `public: true` malgré `public: false`

**Friction** : Les 2 playlists « Mon Daily » sont lues `public: true` par `GET /playlists/{id}` alors que le code envoie `public: false` à la création et via `/followers` à chaque run. `PUT /playlists/{id}` avec `{ "public": false }` répond 200 sans effet, même relu 15 s plus tard

**Cause réelle** : Non identifiée : champ ignoré par Spotify depuis la migration de février 2026, ou lecture trompeuse

**Solution** : Aucune pour l'instant. À vérifier dans l'appli Spotify (la playlist apparaît-elle sur le profil public ?) et, si oui, la passer en privé à la main une fois
