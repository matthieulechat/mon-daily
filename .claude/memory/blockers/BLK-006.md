# BLK-006 — Chasse au 403 générique avant la découverte de la migration Spotify février 2026

| Friction                                                                                                                                                                                                   | Cause réelle                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Solution                                                                                                                                | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `pnpm run generate` échouait avec des 403 génériques ("Forbidden", sans détail) à chaque étape successive (lister les playlists, créer la playlist, ajouter les titres) après le premier run OAuth réussi. | Plusieurs fausses pistes explorées avant la vraie cause (scope OAuth insuffisant, mismatch entre l'id utilisateur passé en CLI et l'id `/me`, compte Spotify "vide"/neuf) — aucune ne collait avec les faits observés (le scope et l'id correspondaient exactement). La vraie cause : Spotify a renommé/déprécié plusieurs endpoints utilisés (`/users/{id}/playlists`, `/playlists/{id}/tracks`) dans une migration "février 2026", découverte en consultant la doc à jour via `find-docs`/ctx7 plutôt que la mémoire d'entraînement. | Remplacement des endpoints dépréciés par leurs équivalents actuels dans `spotify.provider.ts` (cf. [LRN-009](../learnings/LRN-009.md)). | résolu |
