# BLK-002 — `pnpm install` échoue silencieusement (postinstall)

| Friction                                                                                                      | Cause réelle                                                                                                                                                                                                         | Solution                                                                                  | Statut |
| ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ------ |
| `pnpm install` renvoyait exit code 1 sans aucune sortie visible en console, même en relançant plusieurs fois. | pnpm 11.5.2 bloque par défaut les scripts postinstall des dépendances tierces (`ERR_PNPM_IGNORED_BUILDS`, ici `esbuild` via `tsx`) — le message d'erreur n'apparaît qu'en redirigeant stdout+stderr vers un fichier. | `pnpm approve-builds --all` pour approuver les scripts en attente sans prompt interactif. | résolu |
