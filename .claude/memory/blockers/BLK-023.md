# BLK-023 — `vite-plugin-pwa` 1.3.0 refuse `assets-generator` 2.0.0

| Friction | Cause réelle | Solution | Statut |
| -------- | ------------ | -------- | ------ |
| `pnpm peers check` signale un peer non satisfait après l'ajout des deux plugins PWA | `pnpm add -D` a pris `@vite-pwa/assets-generator` 2.0.0 alors que `vite-plugin-pwa` 1.3.0 exige `^1` ; la correction par `pnpm add` a échoué en EPERM (rename de `package.json`), laissant le fichier désynchronisé | Éditer `web/package.json` à la main (`^1.0.2`) puis `pnpm install` ; vérifié par `pnpm peers check` | résolu |
