# BLK-003 — Spotify Dev Mode bloqué sans compte Premium

| Friction                                                                                                                                              | Cause réelle                                                                                                                                                                                     | Solution                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Statut     |
| ----------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Impossible de finaliser la création de l'app Spotify Developer / de tester le flow OAuth pour mon-daily — Baptiste n'a pas de compte Spotify Premium. | Depuis le 11 février 2026, Spotify exige que le PROPRIÉTAIRE d'une app en Development Mode ait un abonnement Premium actif (voir [LRN-004](../learnings/LRN-004.md) pour le détail de la règle). | Pas encore tranché. Options identifiées, de la plus simple à la plus complexe : (1) un proche Premium crée l'app + ajoute Baptiste comme "authorized user" (recommandé, gratuit, zéro changement de code) ; (2) essai gratuit Premium (temporaire) ; (3) pivot vers Deezer en premier (API 100% gratuite, sans restriction équivalente identifiée) ; (4) abonnement Premium payant ; (5) automatisation navigateur (agent-browser) sur open.spotify.com en dehors de l'API officielle (grey zone ToS, plus fragile). | **ouvert** |
