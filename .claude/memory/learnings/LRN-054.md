# LRN-054 — Durée minimale d'un état « en cours »

**Pattern observé** : Quand une action finit quasi instantanément, son état « en cours » est invisible : `await Promise.all([action(), new Promise((r) => setTimeout(r, 900))])` impose une durée mini sans rallonger une requête lente

**Contexte** : Bouton Enregistrer : le spinner passait trop vite pour être lu

**Application future** : Toute confirmation visuelle liée à une opération rapide (sauvegarde, envoi)
