# LRN-054 — Durée minimale d'un état « en cours »

| Pattern observé                                                                                                                                                                                                   | Contexte                                                       | Application future                                                          |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | --------------------------------------------------------------------------- |
| Quand une action finit quasi instantanément, son état « en cours » est invisible : `await Promise.all([action(), new Promise((r) => setTimeout(r, 900))])` impose une durée mini sans rallonger une requête lente | Bouton Enregistrer : le spinner passait trop vite pour être lu | Toute confirmation visuelle liée à une opération rapide (sauvegarde, envoi) |
