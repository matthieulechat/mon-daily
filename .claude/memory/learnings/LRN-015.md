# LRN-015 — Spotify ne renvoie plus le contenu d'une playlist non possédée (migration février 2026)

| Pattern observé                                                                                                                                               | Contexte                                                                                                                                                                                                                       | Application future                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /playlists/{id}` renvoie 404 (y compris pour les métadonnées seules) sur 2 playlists éditoriales Spotify officielles, non possédées par le token utilisé | Tentative d'enrichir le mix musique avec "Hot Hits France" et une playlist découverte — confirmé via la doc à jour : _"playlist responses for non-user playlists will now only return metadata rather than the full contents"_ | Ne plus tenter de lire le contenu d'une playlist Spotify non créée par l'utilisateur authentifié, même officielle/suivie — seule une playlist possédée reste exploitable via l'API. Suite logique de [LRN-001](LRN-001.md) et [LRN-009](LRN-009.md) |
