# LRN-024 — Spotify ne donne pas l'heure : la lire dans le titre

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| `release_date` Spotify est au jour près : pour départager plusieurs éditions du même jour, l'heure se lit dans le titre de l'épisode (formats variables selon la source : "8h00 du 29/09/2026", "29/09 06h00 GMT") | Tri des journaux d'Europe 1 et Journal Monde dans `podcast-source.ts` | Parser chaque format par regex, puis convertir tout en heure murale de Paris via `Intl.DateTimeFormat` (`timeZone: 'Europe/Paris'`) pour comparer ; repli sur l'ordre de l'API si aucune heure |
