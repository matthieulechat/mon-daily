# LRN-050 — Un script générateur ne doit pas écraser son fichier avec 0 résultat

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| `pnpm covers` a réécrit `show-covers.ts` avec 0 pochette quand chaque appel a renvoyé 429 (« ✓ 0/110 pochettes ») | Régénération des pochettes pendant la limite de débit Spotify | Dans un script qui génère un fichier, n'écrire que si au moins un résultat est obtenu (ou conserver l'existant) ; sinon restaurer par git. Garde-fou pas encore ajouté à `fetch-show-covers.ts` |
