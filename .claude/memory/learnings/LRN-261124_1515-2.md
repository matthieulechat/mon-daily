# LRN-261124_1515-2 — Ajouter/retirer un show : 4 fichiers + ligne show_health

**Pattern observé** : Retirer un show touche 4 fichiers : `scripts/config/podcast-shows.ts`, sa copie `supabase/functions/generate-daily/config/podcast-shows.ts`, `scripts/config/show-covers.ts` et `web/src/lib/show-themes.ts`. Il faut aussi supprimer sa ligne dans `show_health` : la vue `dead_shows` lit la table sans filtrer sur la config, donc sans suppression le monitor Kuma « sources » reste rouge. Le tableau des sources de `docs/ROADMAP.md` est historique : on ajoute une note datée, on ne retire pas la ligne. Pour un ajout : mêmes fichiers, pochette 300 px ajoutée à la main (`pnpm covers` refait un appel Spotify par show), nom et derniers épisodes vérifiés via l'API (script tsx `.mts`, cf. [LRN-037](../learnings/LRN-037.md)). Dans les deux cas, redéployer l'Edge Function

**Contexte** : Retrait d'Ultra Run (L'Équipe, dernier épisode 25/08) détecté par `dead_shows`, et ajout de « L'Enquête — par Arcos » (thème Géopolitique) le 2026-11-24. La précédente vague de retraits (2026-10-18) avait suivi le même schéma

**Application future** : Suivre cette checklist à chaque mouvement du pool, puis vérifier : même nombre de shows dans les deux configs, `dead_shows` vide, version déployée contenant le nouvel id
