# LRN-025 — Déclencher à la main une Edge Function protégée par pg_cron

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| Pour lancer immédiatement une Edge Function en `verify_jwt: true`, rejouer via `execute_sql` le `net.http_post` du cron (lu dans `cron.job`), clé lue par sous-requête dans `vault.decrypted_secrets` : le secret ne transite jamais côté agent. Le résultat se lit ensuite dans `net._http_response` (status_code, content), les logs dans `query_logs`. | Redéploiement de `generate-daily` sans token CLI Supabase (déploiement via MCP), test réel sans attendre le cron de 5h UTC. | Tester toute Edge Function planifiée : `select command from cron.job`, rejouer la commande avec `timeout_milliseconds` élevé, puis `select * from net._http_response where id = <request_id>`. |
