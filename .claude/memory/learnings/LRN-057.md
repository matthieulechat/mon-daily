# LRN-057 — `oauth_tokens.expires_at` révèle l'ordre d'exécution du cron

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| `expires_at` vaut refresh + 1 h : il donne l'heure de départ de chaque compte pendant le run. Les logs de l'Edge Function ne portent pas l'id du compte, ce croisement permet d'attribuer chaque ligne de log à son compte | Deux comptes traités à la suite à 05:00 UTC, un seul des deux avec une playlist trop courte | Retrouver « quel compte a produit ce log » sans modifier le code de log ; à défaut, ajouter l'id du compte dans les logs |
