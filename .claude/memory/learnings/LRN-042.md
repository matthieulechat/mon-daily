# LRN-042 — Vérifier une exclusion en relisant la playlist Spotify réelle

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                      | Application future                                                                                                                                                                                                                                                                                                            |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Le filtre `disabledShowIds` dans le code et les logs ne prouvent pas que la playlist est propre : seule la relecture des épisodes réellement présents le prouve. Script jetable (hors dépôt) : lit `oauth_tokens` + `user_settings` via l'API REST Supabase (clé service role de `.env.local`), appelle `/playlists/{id}/items?additional_types=episode,track`, compare `episode.show.id` à `disabled_show_ids` et n'affiche que des noms de shows | Vérification des exclusions de shows de l'UI de réglages, sur 2 comptes, puis après ajout de 3 exclusions et régénération locale (`pnpm run generate <userId>`) : 0 violation | Après toute évolution des réglages ou de la logique de filtrage : régénérer, relire la playlist et comparer aux réglages en base. Garder tokens et clés hors du contexte (le script les lit lui-même). Piège : un show homonyme (« Maintenant, vous savez » vs « … - Culture ») a un autre ID, comparer les IDs, pas les noms |
