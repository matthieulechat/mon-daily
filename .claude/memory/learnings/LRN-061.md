# LRN-061 — Page blanche Vite : console d'abord, puis noms des clés d'env

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| Une erreur levée au chargement d'un module (`throw` au niveau racine) empêche React de monter : page blanche, serveur sans erreur, toutes les requêtes en 200. Seule la console du navigateur le dit | `web/src/lib/supabase.ts` lève une erreur si `SUPABASE_URL` ou `SUPABASE_PUBLISHABLE_KEY` manque ; la seconde était dans `.env.example` mais pas dans `.env.local` | Page blanche : lire la console avant les logs serveur. Variable manquante : comparer les **noms** de clés entre `.env.example` et `.env.local` (regex sur `^NOM=`, sans afficher les valeurs). La clé publique Supabase se récupère par le MCP (`get_publishable_keys`), après avoir vérifié que l'URL du projet est la bonne |
