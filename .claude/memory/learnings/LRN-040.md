# LRN-040 — Exposer une clé publique à Vite : préfixes exacts, bundle vérifié

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| `envPrefix` de Vite expose au navigateur toute variable commençant par le préfixe : un préfixe générique `SUPABASE_` aurait embarqué `SUPABASE_SERVICE_ROLE_KEY`. Lister les variables exactes et vérifier le build par `grep` du bundle | `web/` partage le `.env.local` racine avec les scripts (qui contiennent la `service_role`) ; après le build, `grep -c SERVICE_ROLE dist/assets/*.js` = 0 | Partager un env entre front et back : `envPrefix` en liste de noms exacts, puis `grep` du bundle de production comme contrôle |
