# LRN-007 — Le flag `explicit` de Spotify ne couvre pas les sujets sensibles visés par la modération prévue

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Contexte                                                                                                                                                                                 | Application future                                                                                                                                                                                                                                                            |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sur les 28 shows de la liste des médias (`GET /shows/{id}?market=FR`), 5 sont marqués `explicit: true` par Spotify (Sur le fil, Le Fil Culture G, Maintenant Vous Savez Santé, Code source, Le Crayon) — des podcasts d'actu/culture générale sans lien évident avec la sexualité ou la violence. À l'inverse, "Les Couilles sur la table" (société/genre/sexualité en continu) ressort `explicit: false`. Le flag `explicit` de Spotify n'est donc pas corrélé aux sujets sensibles visés par la modération prévue (guerre, sexualité, violence/faits divers). | Découvert en résolvant les 28 show IDs de la liste des médias ([BDR-008](../decisions/BDR-008.md)) via l'API Client Credentials pour vérifier leur existence et récupérer leur nom réel. | Ne pas utiliser `explicit` comme raccourci ou pré-filtre pour la future modération par mots-clés sur le titre — elle devra reposer entièrement sur le dictionnaire de mots-clés dédié (guerre, sexualité, violence/faits divers), pas sur les métadonnées Spotify existantes. |
