# LRN-033 — Tester du code dépendant de l'heure : `node:test` `mock.timers`

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| `mock.timers.enable({ apis: ['Date'], now })` fixe `new Date()` et `Date.now()` sans dépendance ni injection d'horloge ; `mock.timers.reset()` à la fin de chaque test | Test de `keepClosestByGroup` (podcast-source.test.ts) qui lit l'heure actuelle en interne : 3 cas à 7h20, 9h10 et 11h04 Paris | Script `"test": "tsx --test src/**/*.test.ts"` et `pnpm test`.
