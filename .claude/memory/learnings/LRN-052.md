# LRN-052 — Entrée de page séquencée par `animation-delay`

**Pattern observé** : Une entrée en plusieurs temps (disque, carte, éléments, ondes du logo) se règle avec des `animation-delay` croissants et `backwards`, plus `--i` en variable CSS pour les listes (`min(calc(var(--i) * 45ms), 700ms)`), sans JS

**Contexte** : Page de connexion et cascade des pochettes ; un premier délai de 25 ms était trop rapide pour être perçu

**Application future** : Partir de ~45 ms entre éléments et plafonner le délai total ; valider au ralenti avant de réduire
