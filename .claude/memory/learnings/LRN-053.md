# LRN-053 — Rejouer par `key`, sortir par classe + `onAnimationEnd`

| Pattern observé                                                                                                                                                                                                                                            | Contexte                                                                    | Application future                                                          |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| Rejouer une animation CSS d'entrée à chaque changement : mettre un `key` React sur l'élément. Animer la sortie : état `closing` → classe `-out` (`animation … forwards`), puis démonter dans `onAnimationEnd` (en filtrant `e.target === e.currentTarget`) | Bac de pochettes (`key={openIndex}`) et compteurs « tick » (`key={valeur}`) | Tout élément conditionnel qui doit s'animer en entrée et en sortie sans lib |
