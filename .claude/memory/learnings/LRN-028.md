# LRN-028 — `python` du shell Bash sous Windows peut ne rien exécuter ; ne pas valider l'ancien code

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| Sous Windows, `python` dans Bash peut être l'alias Microsoft Store (« Python was not found ») : un script d'édition ne s'exécute pas et le fichier reste intact. Une vérification enchaînée (`tsc --noEmit && echo OK`) affiche alors `OK` sur l'ancien code | Édition de `generate.ts` par script Python ; le `OK` de `tsc` ne prouvait rien | Éditer avec l'outil d'édition plutôt qu'un script ; relire la sortie d'une commande qui échoue avant de conclure ; relancer la vérification après l'édition réelle |
