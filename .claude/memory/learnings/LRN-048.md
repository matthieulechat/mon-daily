# LRN-048 — Une requête `pg_net` « bloquée » est en vol, pas coincée

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                       | Contexte                                                                                                                             | Application future                                                                                                                                                                                                                  |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Une requête `net.http_post` reste dans `net.http_request_queue` tant qu'elle n'a pas reçu de réponse : elle n'est pas « en attente de worker » mais en vol chez l'Edge Function. Vider la file n'arrête rien. La seule issue est la réponse (ou le 546 `WORKER_RESOURCE_LIMIT` vers 2 min 30), lisible ensuite dans `net._http_response`. Le vrai état se lit dans `function_logs` (dernier message avant le silence) | Deux rejeux de `generate-daily` (n°13 et n°14) ont semblé bloqués ; la n°13 avait en fait fini en 546 avant même la purge de la file | Face à une requête `pg_net` sans réponse : lire `query_logs` (`function_logs`) pour voir où la fonction s'est arrêtée, attendre la fin, ne pas purger la file ni redémarrer le worker. Compléter [LRN-025](../learnings/LRN-025.md) |
