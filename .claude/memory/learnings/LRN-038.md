# LRN-038 — Id de ressource stocké : la config idempotente se réapplique à chaque run

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| Quand on stocke l'id d'une ressource distante au lieu de la retrouver, toute étape faite « à la création seulement » (pochette, réglages) n'est plus jamais rejouée : si la ressource a été recréée ou modifiée à la main, elle reste incomplète sans erreur ni log | Playlist « Mon Daily » : après [BDR-029](../decisions/BDR-029.md), l'upload de pochette n'était fait qu'à la création ; une playlist sans pochette est restée telle quelle chez un compte | Appliquer chaque propriété idempotente (image, visibilité, contenu) à chaque run ; ne garder « à la création » que ce qui ne peut pas être rejoué |
