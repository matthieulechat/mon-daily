# LRN-043 — Contrôle custom (potard) : vrai input masqué dessous

**Pattern observé** : Un contrôle dessiné en `div` n'est pas utilisable au clavier ni au lecteur d'écran. On garde un vrai `<input type="range">` en `sr-only` comme base, et le visuel custom (`aria-hidden`) le pilote.

**Contexte** : Potard de durée dans `Knob.tsx` (glisser haut/bas), lié au même état que l'input.

**Application future** : Pour tout contrôle custom (potard, toggle, slider) : natif masqué dessous, focus affiché via `:focus-within` sur le parent.
