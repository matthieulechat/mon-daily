# LRN-008 — Un endpoint batch Spotify peut être plus restreint que son équivalent single-item, même token

| Pattern observé                                                                                                                                                                                                                                                                                                               | Contexte                                                                                                                                                                                                                 | Application future                                                                                                                                                                                                                                                                                         |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Avec un token Client Credentials Spotify, `GET /shows?ids=<liste>` (batch, jusqu'à 50 IDs) a répondu `403 Forbidden`, alors que `GET /shows/{id}` (single) sur l'un des mêmes IDs a répondu `200` sans changer de token ni de scope. Le batch et le single n'ont donc pas forcément le même niveau d'accès sur l'API Spotify. | Découvert en résolvant les 28 show IDs de la liste des médias podcast ([BDR-008](../decisions/BDR-008.md) / [BLK-005](../blockers/BLK-005.md)) — le 403 n'incluait aucun détail exploitable dans le corps de la réponse. | Face à un 403 inattendu sur un endpoint batch Spotify (ou Web API plus largement), tester en premier le même appel en version single-item avant de chercher une erreur de token/scope/permissions — un 403 batch + 200 single indique une restriction sur l'endpoint lui-même, pas sur l'authentification. |
