# LRN-063 — Profil Spotify déjà dans `session.user.user_metadata`

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| Après un login OAuth Spotify via Supabase Auth, `session.user.user_metadata` contient déjà `name` et `avatar_url` : pas besoin d'appeler `/v1/me` ni d'avoir un token Spotify côté web | Affichage du nom et de la photo dans l'en-tête de `SettingsPage.tsx`. Le type est `Record<string, any>` : le restreindre à l'usage. Les valeurs ne sont rafraîchies qu'au login | Avant d'ajouter un appel API pour une info de profil, regarder `user_metadata`. Prévoir un repli (initiale, identifiant) : un compte peut n'avoir ni photo ni nom |
