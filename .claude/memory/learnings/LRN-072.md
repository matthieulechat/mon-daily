# LRN-072 — Deux filtres fusionnés : garder un message de log par cause

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| Le filtre de durée a été ajouté dans le même `.filter` que la fraîcheur, avec un seul message d'exclusion (« aucun épisode frais sous la durée max »). À la première génération réelle, les shows simplement trop anciens (dernier épisode de janvier) s'affichaient avec ce message, ce qui masquait la vraie cause | Régénération du daily de Matthieu le 2026-10-07, juste après l'ajout du réglage « durée max d'un épisode » | Quand on ajoute un critère d'exclusion à un filtre existant : un filtre par cause et un message par cause. Mettre dans le message la donnée utile pour ajuster le réglage (ici le nombre d'épisodes frais et la durée du plus court). Relire les logs d'un run réel après tout ajout de filtre |
