# LRN-077 — Synchroniser une copie Edge Function : `cp` écrase les imports `.ts`

**Pattern observé** : Copier `scripts/core/x.ts` vers `supabase/functions/generate-daily/core/x.ts` remet les imports relatifs en `.js`, que Deno ne résout pas

**Contexte** : Ajout d'un filtre dans `podcast-source.ts` puis copie vers l'Edge Function ; un `diff` filtré par rtk affichait « identique » (voir GLRN-352), seul `git diff -w` a montré les imports cassés avant déploiement

**Application future** : Après chaque `cp` d'un fichier qui importe : `sed -i -E 's#^(import .* from "\.\.?/[^"]+)\.js";#\1.ts";#' <copie>` puis contrôle `git diff -w <copie>`. Les fichiers sans import (`podcast-shows.ts`) se copient tels quels. `npx -y deno@2 check supabase/functions/generate-daily/index.ts` valide le tout (2 erreurs préexistantes dans `oauth.service.ts`)
