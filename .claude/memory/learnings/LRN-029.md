# LRN-029 — Prévisualiser un tirage aléatoire en lecture seule sur données réelles

| Pattern observé                                                                                                                                                                                                                                                  | Contexte                                                                                                                                              | Application future                                                                                                                                                                                                         |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un script temporaire jetable (`src/_preview.ts`, supprimé après usage), rejoué sur les vrais comptes sans écrire la playlist, a montré ce que le raisonnement n'aurait pas révélé : 17 titres d'un même artiste sur 51, pools trop petits, arrondis à 51 au lieu de 50 | Choix du ratio et du plafond par artiste du mix musique : les tirages sur 2 comptes ont guidé le choix (plafond 5) et montré qu'un plafond seul ne suffit pas | Avant de figer un paramètre de sélection aléatoire, l'observer sur les vrais comptes avec un script lecture seule, puis le supprimer. Le script réplique la logique sans importer le module si celui-ci exécute `main()` à l'import |
