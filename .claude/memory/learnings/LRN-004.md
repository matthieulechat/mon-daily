# LRN-004 — Spotify Dev Mode exige Premium du owner (fév 2026), pas des users

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                         | Contexte                                                                                                   | Application future                                                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Depuis le 11 février 2026, Spotify exige que le PROPRIÉTAIRE (créateur) d'une app en "Development Mode" ait un abonnement Premium actif — mais cette exigence ne s'applique PAS aux "authorized users" (max 5) qui s'authentifient ensuite via Authorization Code sur cette app. Extended Quota Mode (qui dispenserait de cette règle) est fermé aux projets perso depuis mai 2025 (réservé aux organisations avec ≥250k utilisateurs actifs mensuels). | Découvert en tentant de créer l'app Spotify Developer pour mon-daily — Baptiste n'a pas de compte Premium. | Pour toute future intégration Spotify Web API perso sans compte Premium : faire créer l'app par un proche qui a Premium et se faire ajouter comme "authorized user", plutôt que chercher une exemption côté Spotify (Extended Quota Mode fermé, Client Credentials n'aide pas — la plupart des endpoints utiles ont aussi été retirés de ce flow en fév. 2026). |
