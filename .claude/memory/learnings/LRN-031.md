# LRN-031 — Épisode « manquant » : vérifier d'abord s'il est publié

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| Un épisode attendu qui n'apparaît pas n'est pas forcément un bug de filtre : la source peut ne pas l'avoir encore publié | "Journal 30/09/2026 09h00 GMT" de Journal Monde absent d'une génération faite vers 11h04 Paris ; le 08h00 GMT était le plus récent disponible. Une relance plus tard l'a fait apparaître | Avant de toucher au code, relancer plus tard ou lister les épisodes réels du show (date + titre). Les éditions horaires sont publiées avec un léger décalage après l'heure du titre |
