# LRN-001 — Spotify a tué `/recommendations` pour les apps post-nov 2024

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                  | Contexte                                                                                                                                                                      | Application future                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Spotify a déprécié en novembre 2024 les endpoints `/recommendations`, `/audio-features` et `/related-artists` pour toute application créée après cette date. Il n'existe donc plus de moteur de recommandation "boîte noire" gratuit — la personnalisation doit être reconstruite à la main à partir des données déjà accessibles (top tracks/artists, genres dominants, recherche par mot-clé). | Découvert en concevant le remplaçant du Daily Drive : la logique de découverte musicale (`discovery-engine.ts`) ne peut pas s'appuyer sur l'API de recommandation officielle. | Avant d'intégrer une nouvelle plateforme (Deezer, Apple Music), vérifier systématiquement la date de dépréciation des endpoints de recommandation/audio-analysis avant de concevoir l'algo de découverte autour. Ne jamais supposer qu'un endpoint "recommandation" public reste disponible pour une nouvelle app. |
