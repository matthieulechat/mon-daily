# LRN-011 — `public:false` à la création peut être ignoré par Spotify (réglage compte)

| Pattern observé                                                                                                                                                                                                                                       | Contexte                                                                                                                                                                              | Application future                                                                                                                                                                                                                                                                     |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `POST /me/playlists` avec `{"public": false}` a créé une playlist marquée `"public": true` dans la réponse de l'API — le flag de création semble parfois ignoré, probablement au profit d'un réglage de confidentialité par défaut du compte Spotify. | Playlist "Mon Daily" visible publiquement malgré `public: false` explicite dans le body de création, repéré par Baptiste via un screenshot de la page playlist ("Playlist publique"). | Ne jamais faire confiance au flag `public` envoyé à la création d'une playlist Spotify : le confirmer explicitement via un `PUT /playlists/{id}` juste après, et le répéter à chaque appel ultérieur acceptant ce paramètre (ex. `/followers`) — omis, il repasse par défaut à `true`. |
