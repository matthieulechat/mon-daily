# LRN-009 — Migration Spotify "février 2026" a renommé/cassé des endpoints utilisés

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                     | Contexte                                                                                                                                                                                                                                                     | Application future                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Le code `spotify.provider.ts`, écrit sur la base de la connaissance d'entraînement du modèle, appelait des endpoints Spotify renommés/dépréciés depuis une migration "février 2026" documentée par Spotify (`POST /users/{id}/playlists` → `POST /me/playlists`, `PUT /playlists/{id}/tracks` → `PUT /playlists/{id}/items`) — chacun renvoyait un 403 générique sans indice utile. | Premier run réel de `pnpm run generate`, après avoir déjà corrigé le scope et le mismatch d'id supposés — les 403 persistaient à chaque étape (lister, créer, ajouter des titres), poussant à chercher la doc Spotify à jour plutôt que continuer à deviner. | Pour toute API tierce bien connue mais à évolution rapide (Spotify, Stripe, etc.), consulter la doc à jour (`find-docs`/ctx7) dès qu'une erreur générique (403/400 sans détail) persiste malgré des corrections logiques évidentes — ne pas supposer que la connaissance d'entraînement du modèle est à jour. Tester empiriquement une route "remplaçante" documentée avant de l'adopter : elle peut être non fonctionnelle malgré sa présence dans la doc (cf. [BDR-009](../decisions/BDR-009.md)). |
