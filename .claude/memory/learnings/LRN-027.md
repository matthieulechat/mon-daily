# LRN-027 — `src/` et la copie Edge Function divergent : répliquer à la main puis redéployer

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| `supabase/functions/generate-daily/` contient sa propre copie de la logique de `src/` (generate, podcast-source, podcast-shows). Une modif faite seulement dans `src/` laisse le cron quotidien sur l'ancien comportement, sans aucune erreur visible | Découvert après le commit `a359df2` (mix sans plafond + `maxAgeDays`) : la copie gardait les anciens plafonds | Avant de committer une modif de logique métier, grep les mêmes symboles dans `supabase/functions/generate-daily/`, répliquer, puis redéployer la fonction. Signaler dans la réponse si la copie n'est pas synchronisée |
