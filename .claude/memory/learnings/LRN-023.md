# LRN-023 — Un seul champ ne suffit pas si chacun peut individuellement faillir

| Pattern observé                                                                                                                                                                                                                                                                                                             | Contexte                                                                                                                                                                                                                                                     | Application future                                                                                                                                                                                                                                          |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Classifier un item d'après un seul champ de métadonnées (titre) peut échouer par absence de motif ; basculer entièrement vers un autre champ (description) peut échouer différemment si ce champ est parfois tronqué par l'API — la solution robuste combine les deux signaux en OR, chacun compensant les trous de l'autre | HugoDécrypte : le titre seul ratait les actus du jour sans date en suffixe ; la description seule aurait raté certains épisodes `(Pop)` dont Spotify tronque le début du texte sur l'endpoint liste — le croisement titre OU description couvre les deux cas | Avant de choisir "le" champ fiable pour détecter un motif textuel, vérifier sur un échantillon réel si CHAQUE champ candidat est individuellement complet ; si aucun ne l'est à 100 %, combiner plusieurs signaux en OR plutôt que de trancher pour un seul |
