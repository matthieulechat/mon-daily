# LRN-045 — Vérifier `pnpm peers check` après l'ajout de plugins couplés

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| Deux paquets d'un même écosystème peuvent se résoudre sur des majeures incompatibles ; un `pnpm add` en EPERM peut laisser `package.json` à moitié modifié | Ajout de `vite-plugin-pwa` + `@vite-pwa/assets-generator` | Lancer `pnpm peers check` après chaque ajout de plugins couplés ; si EPERM, relire `package.json` et corriger à la main avant `pnpm install` |
