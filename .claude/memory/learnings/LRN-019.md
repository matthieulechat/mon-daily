# LRN-019 — Contenu généré en JS invisible hors projet dans le Browser pane

**Pattern observé** : Un fichier HTML hors du dossier projet ouvert dans le Claude Browser pane est rendu en instantané statique, sans JS : une page qui construit son contenu en JS y apparaît vide

**Contexte** : Page de revue des podcasts générée dans le scratchpad, lignes créées en JS → "je ne vois pas de lien"

**Application future** : Écrire le contenu utile (liens, lignes de tableau) directement dans le HTML, JS réservé aux interactions ; dire à l'utilisateur d'ouvrir le fichier dans son navigateur si les interactions comptent. Voir aussi GLRN-288
