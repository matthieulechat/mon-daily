# LRN-059 — Catégorie par épisode : vérifier qu'une file la consomme

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| Une catégorie calculée par élément ne sert à rien si le tri en aval ne lit pas le pool où l'élément se trouve. Ici le tri était asymétrique : la file actu lisait les deux pools, la file thématique un seul | Les interviews de HugoDécrypte (show `actu`) étaient étiquetées `thematique` puis jetées, alors que le changelog annonçait qu'elles « passaient en thématique ». Slate (show `thematique`) marchait dans les deux sens, ce qui masquait le trou | Quand un classement se fait en deux temps (par conteneur puis par élément), suivre un élément de chaque catégorie effective jusqu'à la file qui le tire, dans les deux sens. Ne pas se fier à un cas qui marche pour conclure que le mécanisme est symétrique |
