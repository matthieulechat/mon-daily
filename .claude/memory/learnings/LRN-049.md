# LRN-049 — Nom et pochette d'un show sans l'API Spotify

**Pattern observé** : La page publique `open.spotify.com/show/ID` donne `og:title` (nom du show) et `og:image` (pochette). Le préfixe `ab6765630000ba8a` (640 px) devient `ab67656300005f1f` (300 px). oEmbed renvoie le titre du dernier épisode, pas le nom du show

**Contexte** : API Spotify en 429 pendant l'ajout de 48 podcasts (cf. [ZBLK-024](../archive/blockers/ZBLK-024.md))

**Application future** : Pour nommer ou illustrer de nouveaux shows quand l'API est limitée, lire la page publique ; garder `pnpm covers` pour le régime normal. Aussi pour ajouter quelques shows à un grand pool : `pnpm covers` refait 1 appel API par show sur tout le pool (146 le 2026-10-14), alors que lire les N pages publiques et ajouter leurs URL à `show-covers.ts` ne touche pas au budget API
