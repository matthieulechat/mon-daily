# LRN-049 — Nom et pochette d'un show sans l'API Spotify

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| La page publique `open.spotify.com/show/ID` donne `og:title` (nom du show) et `og:image` (pochette). Le préfixe `ab6765630000ba8a` (640 px) devient `ab67656300005f1f` (300 px). oEmbed renvoie le titre du dernier épisode, pas le nom du show | API Spotify en 429 pendant l'ajout de 48 podcasts (cf. [ZBLK-024](../archive/blockers/ZBLK-024.md)) | Pour nommer ou illustrer de nouveaux shows quand l'API est limitée, lire la page publique ; garder `pnpm covers` pour le régime normal |
