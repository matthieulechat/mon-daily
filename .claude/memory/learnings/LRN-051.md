# LRN-051 — `scale`/`translate`/`rotate` se composent avec `transform`

| Pattern observé                                                                                                                                                                            | Contexte                                                                                                                             | Application future                                                                                                      |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| Les propriétés individuelles `scale`, `translate`, `rotate` se composent avec `transform` au lieu de l'écraser : on peut animer l'apparition d'un élément qui tourne déjà via `@keyframes` | Vinyle de fond en rotation continue (`vinylspin` sur `transform`) + `vinyl-in` sur `scale`/`translate`, deux animations en parallèle | Toute entrée sur un élément déjà animé en `transform` : utiliser les propriétés individuelles pour la seconde animation |
