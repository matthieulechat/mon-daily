# LRN-021 — Container mixte : classifier chaque item par motif de titre

| Pattern observé                                                                                                                                                                                                                                                                      | Contexte                                                                                                                                                                                                                 | Application future                                                                                                                                                                                                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un container (show, flux, dossier...) peut mélanger plusieurs catégories logiques sans que la source les distingue ; quand un motif textuel constant existe (préfixe de titre standardisé), reclasser au niveau item plutôt que de forcer une catégorie unique sur tout le container | "Le journal d'Europe 1" catégorisé `actu` dans `podcast-shows.ts`, mais certains épisodes sont en réalité de la météo — reconnaissables au préfixe systématique "La météo de ...h... du .../.../." dans le titre Spotify | Avant de scinder une source (nouveau show, nouveau flux) pour isoler une sous-catégorie, vérifier si un motif texte fiable (préfixe/suffixe de titre, tag dans les métadonnées) permet de reclasser au niveau item sans toucher au découpage des sources |
