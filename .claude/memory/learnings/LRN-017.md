# LRN-017 — Spotify : l'oEmbed d'un show renvoie le dernier épisode, pas le show

**Pattern observé** : `open.spotify.com/oembed?url=<show>` renvoie dans `title` le titre du **dernier épisode**, pas le nom du show. Le nom du show est dans `og:title` de la page `open.spotify.com/show/<id>` (`curl -A 'Mozilla/5.0'`, sans token ; entités HTML type `&#x27;` à décoder)

**Contexte** : Résolution des noms de 27 shows à partir de leurs liens, sans token Spotify disponible dans la session

**Application future** : Nom d'un show → `og:title`. Vérifier qu'un show publie encore → oEmbed (le titre du dernier épisode contient souvent la date)
