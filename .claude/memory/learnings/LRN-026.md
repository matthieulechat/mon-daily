# LRN-026 — Vérifier le format de titre de chaque nouveau show

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| Les titres d'un même diffuseur varient : `du 29/09/2026`, `du mardi 29 septembre 2026`, `du lundi 28 septembre` (sans année), avec ou sans résumé en préfixe, heures `6h` ou `06h00`. Un parseur validé sur un show ne l'est pas sur le suivant. | Ajout de 6 journaux France Inter : le parseur existant ne comprenait que le format `dd/mm/yyyy`. Vu en lisant les titres via `open.spotify.com/oembed` avant d'écrire le code. | À chaque ajout d'un show à parseur d'heure : lire son dernier titre via oEmbed, tester la regex dessus, rendre optionnels les éléments variables (année, jour de semaine). Un test où le fallback donne le même résultat que le succès ne prouve rien : contrôler que la date est vraiment lue. |
