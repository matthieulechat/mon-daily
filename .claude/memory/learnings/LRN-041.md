# LRN-041 — Spotify OAuth : `show_dialog=true` pour changer de compte

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| Après une déconnexion de l'appli, Spotify reconnecte automatiquement le même compte grâce à sa session navigateur, sans écran de choix. `queryParams: { show_dialog: 'true' }` dans `signInWithOAuth` force l'écran d'autorisation | Test de connexion du second compte dans l'UI : les logs Auth montraient un `logout` suivi aussitôt d'un `login` oauth Spotify | Tout projet avec login Spotify multi-comptes : ajouter `show_dialog`, ou passer par une fenêtre privée pour tester un autre compte |
