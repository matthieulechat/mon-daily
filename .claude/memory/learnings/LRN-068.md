# LRN-068 — Hook de formatage PostToolUse : il reformate le fichier entier à chaque `Edit`

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| Sur un fichier jamais passé au formateur (entrées sur une ligne, fichier généré), un `Edit` de 20 lignes déclenche le hook qui reformate tout : 400 lignes de diff pour `podcast-shows.ts`, 360 pour `show-covers.ts`. Les fichiers du repo sont en CRLF dans l'arbre de travail, ce qui fait échouer une ancre multi-lignes écrite en LF | Ajout des shows régionaux le 2026-10-05 | Regarder `git diff --stat` après le premier `Edit` d'un fichier dense. Si le diff explose : `git checkout -- <fichier>` puis appliquer l'ajout par un script Node écrit dans un fichier (lecture normalisée en LF, réécriture en CRLF, ancre vérifiée avant remplacement). Voir aussi GLRN-103 pour le rejet de `Write` après passage du hook |
