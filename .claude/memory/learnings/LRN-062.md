# LRN-062 — `pg_cron` en UTC : heure locale fixe par double horaire filtré

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| Pour viser une heure locale fixe malgré l'heure d'été, planifier le job sur les deux heures UTC possibles et filtrer dans la commande avec `where extract(hour from now() at time zone '<zone>') = <heure>`. Postgres résout le décalage via tzdata, le jour de bascule compris (le changement a lieu à 1h UTC) | `pg_cron` sur Supabase tourne en UTC sans suivi de l'heure d'été ; `select net.http_post(...) where <condition>` suffit à annuler l'appel | Tout job quotidien qui doit tomber à heure locale fixe. Vérifier le filtre avec `extract(hour from timestamptz '<date été/hiver>' at time zone '<zone>')` avant de l'appliquer |
