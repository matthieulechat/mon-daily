# LRN-067 — Edge Function et interface web : deux déploiements indépendants

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| `pnpm deploy:edge` envoie les fichiers locaux de `supabase/functions/generate-daily`, sans passer par Git. L'interface web, elle, n'est déployée par Vercel qu'après un push sur `main`. On peut donc avoir une fonction à jour et un site en retard, ou l'inverse. Une migration additive (colonne avec valeur par défaut) passe sans casser l'ancienne interface encore en ligne | Après l'ajout des sources régionales : fonction déployée (v14) mais aucun déploiement Vercel, parce que rien n'était commité | Annoncer les deux déploiements séparément. Pour prouver que la fonction est à jour sans la lancer : comparer `updated_at` de `list_edge_functions` aux dates de modification des fichiers locaux (aucun fichier plus récent) et vérifier que les copies sont identiques à `scripts/` |
