# LRN-014 — Le pool éligible pour un tirage au sort doit être compté au niveau de l'unité atomique, pas de l'agrégat

| Pattern observé                                                                                                                                                                                                                        | Contexte                                                                                                                                                                                                                               | Application future                                                                                                                                                                                                                                                 |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Une estimation "le pool s'épuise en ~4 jours" s'est révélée fausse : le code ne récupérait que le dernier épisode par show (agrégat), alors que plusieurs épisodes par show pouvaient être éligibles individuellement (unité atomique) | Sélection de podcasts par tirage au sort dans `mon-daily` — corrigé en récupérant tous les épisodes récents éligibles par show au lieu du seul dernier (45 épisodes actu / 34 thématiques mesurés sur un run réel, contre 13/15 shows) | Avant de conclure qu'un pool de candidats pour un tirage au sort est trop petit, vérifier qu'on échantillonne au bon niveau de granularité — l'agrégat (show, dossier, catégorie) sous-estime souvent largement le nombre réel d'unités individuellement éligibles |
