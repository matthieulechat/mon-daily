# LRN-016 — Un item d'un tableau paginé Spotify peut être `null` à une position arbitraire

| Pattern observé                                                                                                                                                                                        | Contexte                                                                                         | Application future                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `data.items[0]` était `null` pour un show ("Gaspard G") alors que `items[1]` contenait un épisode valide et récent — le code concluait à tort "aucun épisode disponible" en ne regardant que l'index 0 | `GET /shows/{id}/episodes` — un épisode précis peut être restreint indépendamment du show entier | Sur toute réponse paginée Spotify, filtrer les `null` sur l'ensemble du tableau avant de traiter les éléments, jamais se fier à la position (surtout pas l'index 0) |
