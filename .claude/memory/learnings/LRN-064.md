# LRN-064 — Vérifier la planification réelle avant d'écrire une heure dans l'UI

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| Une heure demandée pour un libellé (« mise à jour à 7h ») est une affirmation sur le système : la confronter à la planification réelle avant de l'écrire | Le cron tournait à 5h UTC, soit 6h en hiver : « 7h » en dur aurait été faux trois semaines plus tard. Le signaler a fait émerger le vrai besoin (7h toute l'année), réglé côté cron plutôt que côté texte | Pour tout texte qui cite un horaire, un délai ou une fréquence : lire la source (`cron.job`, config, doc) et signaler l'écart plutôt que d'afficher la valeur demandée ou de la contourner en silence |
