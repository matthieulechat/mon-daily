# LRN-070 — Durées d'épisodes : le jeton d'application suffit

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| `GET /shows/{id}/episodes?market=FR&limit=10` répond avec un jeton *client credentials* (même obtention que `fetch-show-covers.ts`), sans jeton utilisateur ni id de compte. 127 requêtes en séquence, 250 ms d'écart, arrêt prévu au premier 429 : aucun 429 | Mesure des durées pour caler les touches du réglage, 2026-10-07. Script jetable écrit dans `scripts/` (pour résoudre `env` et `PODCAST_SHOWS`), supprimé après usage | Pour toute statistique sur les shows (durées, fréquence de publication, fraîcheur) : jeton d'application, une requête par show, écart ≥ 250 ms, arrêt au premier 429. Pas besoin de toucher à `oauth_tokens` |
