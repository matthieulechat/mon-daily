# LRN-261126_1222-1 — Show `alsoThematic` : un id dans ACTU_THEMES et SHOW_THEMES

**Pattern observé** : un show en double classement (`alsoThematic`, ou `actuTitleIncludes`) apparaît dans les deux sections de `ShowsPicker`. Son id doit donc figurer à la fois dans `ACTU_THEMES` et dans `SHOW_THEMES` (`web/src/lib/show-themes.ts`). S'il manque dans l'une des deux listes, le show tombe dans la pile « Autres » de cette section.

**Contexte** : le commit `955452d` (« fix theme placement ») a retiré HugoDécrypte de la pile « Interviews », en prenant l'id pour un doublon de « Flashs & magazines ». Hugo s'est retrouvé dans « Autres » en prod. Restauré dans `c84f1c9`.

**Application future** : avant de « dédoublonner » un id dans `show-themes.ts`, vérifier s'il porte `alsoThematic` ou `actuTitleIncludes` dans `scripts/config/podcast-shows.ts`. Si c'est le cas, le doublon est voulu.
