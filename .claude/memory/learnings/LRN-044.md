# LRN-044 — Prévisualiser une page authentifiée : fausse session Supabase

**Pattern observé** : Pour voir une UI protégée sans passer par OAuth, injecter dans `localStorage` la clé `sb-<ref>-auth-token` avec un token factice, un `expires_at` futur et le `user_metadata` utile (ici `provider_id`). Les appels réseau échouent (statut `ERROR`), mais l'UI se rend.

**Contexte** : Aperçu des réglages de Mon Daily sans connexion Spotify.

**Application future** : À faire en aperçu local seulement, et supprimer la clé ensuite (`removeItem`).
