# LRN-002 — pnpm bloque les postinstall scripts par défaut

| Pattern observé                                                                                                                                                                                                                           | Contexte                                                                                                          | Application future                                                                                                                                                                     |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Depuis pnpm 11+, `pnpm install` bloque silencieusement (exit code 1, aucune sortie visible sans redirection) les scripts postinstall des dépendances tierces (`ERR_PNPM_IGNORED_BUILDS`) tant qu'ils ne sont pas approuvés explicitement. | Rencontré sur le scaffold Node/TS neuf de mon-daily : `tsx` dépend d'`esbuild`, dont le postinstall était ignoré. | Après un `pnpm install` qui échoue sans message clair, lancer `pnpm approve-builds --all` (ou cibler des paquets précis avec `pnpm approve-builds <pkg>`) avant de chercher plus loin. |
