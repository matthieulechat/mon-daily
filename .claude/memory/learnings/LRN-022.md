# LRN-022 — Client Credentials Spotify suffit pour un show public

| Pattern observé                                                                                                                                                                                         | Contexte                                                                                                                                                                                                       | Application future                                                                                                                                                                                                                                               |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un endpoint Spotify en lecture publique (`GET /shows/{id}/episodes`) est accessible via le flow Client Credentials (`client_id`+`client_secret` uniquement), sans passer par le token OAuth utilisateur | Claude a supposé à tort ne pas pouvoir vérifier le format réel des titres/descriptions d'un show faute de "token en main" — Baptiste a fait remarquer que les credentials client dans `.env.local` suffisaient | Avant de dire "pas de token disponible" sur un endpoint Spotify en lecture, vérifier s'il s'agit d'une ressource publique (show, épisode, artiste) exploitable en Client Credentials plutôt que de supposer qu'il faut le flow utilisateur complet de `login.ts` |
