# LRN-071 — Page derrière OAuth : fausse session locale pour vérifier le rendu

| Pattern observé | Contexte | Application future |
| --------------- | -------- | ------------------ |
| Le volet navigateur ne peut pas passer la connexion Spotify. Écrire une session factice dans `localStorage` sous la clé `sb-<project-ref>-auth-token` (jeton au format JWT non signé, `expires_at` dans le futur, `user.user_metadata.provider_id`) puis recharger suffit pour que `getSession()` la renvoie et que la page de réglages s'affiche avec les valeurs par défaut | Vérification de l'afficheur et des touches du réglage « durée max d'un épisode » sur `localhost:5173`, 2026-10-07 | Utilisable pour vérifier rendu, clic, clavier et mobile. Limites à annoncer : les appels à la base répondent 401 (statut « ERROR » à l'écran), donc ni le chargement ni l'enregistrement réels ne sont testés. Retirer la clé et recharger une fois la vérification finie |
