# BDR-023 — Podcasts multi-éditions : garder l'épisode le plus proche de l'heure

**Décision** : Flag `latestOnly` sur les shows publiés plusieurs fois par jour ("Le journal d'Europe 1", "Journal Monde") : par catégorie effective, on ne garde que l'épisode dont l'heure lue dans le titre (Paris ou GMT) est la plus proche de l'heure actuelle à Paris (`keepClosestToNow`, `podcast-source.ts`). L'heure cible deviendra un réglage utilisateur avec la page de personnalisation

**Pourquoi** : Avoir des journaux les plus frais possible plutôt que plusieurs éditions de la même journée dans le pool

**Alternatives considérées** : Se fier à l'ordre de l'API (écarté : pas d'heure côté Spotify, cf. [LRN-024](../learnings/LRN-024.md)) ; ne garder que le plus tôt disponible
