# BDR-050 — Modération par sujet, sur le titre des épisodes thématiques

**Décision** : Colonne `user_settings.moderated_topics` (vide par défaut, CHECK limité à `guerre`, `sexualite`, `violence`), un interrupteur par sujet dans l'interface (carte « Écarter les sujets »), motifs dans `scripts/config/moderation.ts` (titre en minuscules sans accents, mots entiers ou débuts de mot). Seuls les épisodes de catégorie `thematique` sont filtrés. Les sujets de société restent dans le mix : sexisme, violences (conjugales, sexuelles, policières) et féminicide ne sont pas filtrés ; seuls les faits violents (meurtre, viol, attentat…) et la sexualité au sens strict (sexe, sexuel, sexualité…) le sont

**Pourquoi** : Les journaux parlent de guerre presque chaque jour : filtrer l'actu viderait l'ouverture du mix. Désactivée par défaut pour ne rien changer aux deux comptes existants sans leur accord. Baptiste juge le sexisme et les violences comme des sujets importants, pas à écarter

**Alternatives considérées** : Un seul interrupteur global ; activée par défaut ; filtrage de l'actu aussi ; radicaux larges `sex\w*` et `viol` + `violence(s)`/`violent(e)(s)` (retirés le jour même)
