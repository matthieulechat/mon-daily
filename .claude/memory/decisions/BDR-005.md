# BDR-005 — Sourcer les podcasts via 3 shows Spotify natifs, pas RSS

| Décision                                                                                                                                                                                                                                                                                                                                  | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                         | Alternatives considérées                                                                                                                                                                         | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| Sourcer les épisodes d'actu (Le Monde, France Info) via l'endpoint Spotify natif `GET /shows/{id}/episodes` sur 3 shows pilotes — L'Heure du Monde (`2ceI3IzPwHJywfQTAtrQSI`), Les informés de franceinfo (`4wyNV1lUV1Wm2wqN91mEx6`), 8h30 franceinfo (`6RHQXwIlOrjdZ86forQKlw`) — plutôt que le parser RSS prévu dans `ARCHITECTURE.md`. | Les flux RSS publics de ces médias renvoient des articles texte, pas des épisodes audio jouables — inexploitables pour un mix Spotify de toute façon. Les 3 shows visés existent nativement sur Spotify, réutilisent le pattern `spotifyFetch` déjà écrit, zéro nouvelle dépendance, et le risque documenté "flux RSS qui changent de format" disparaît. Autres sources à ajouter plus tard (AFP...) une fois ces 3 validées comme test initial. | Parser RSS tel que documenté dans `ARCHITECTURE.md` (`sources/rss-fetcher.ts`) ; recherche `search?type=episode` par mot-clé (rejeté : moins déterministe qu'un fetch direct par show ID connu). | actif  |
