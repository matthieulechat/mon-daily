# BDR-020 — Edge Function Supabase + `pg_cron` retenu plutôt que cron self-hosté

**Décision** : Automatisation quotidienne via Edge Function Supabase (`supabase/functions/generate-daily`), déclenchée par `pg_cron`/`pg_net`, malgré le coût du portage Deno (imports `.js`→`.ts`, `config/env.ts` dupliqué en version `Deno.env.get()`, specifiers `npm:`)

**Pourquoi** : 100% cloud, rien à laisser allumé chez Baptiste. Question posée explicitement avant de se lancer, tranchée par Baptiste malgré la friction de portage identifiée en amont dans le plan

**Alternatives considérées** : Cron + PM2 sur le NAS Synology (pattern déjà utilisé sur d'autres projets perso, cf. GLRN sur `stop_exit_codes`) — zéro portage, `generate.ts` tourne tel quel en Node, mais dépend de la disponibilité du NAS ; écarté par choix explicite de Baptiste
