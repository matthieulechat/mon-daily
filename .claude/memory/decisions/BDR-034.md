# BDR-034 — Pochettes de podcasts figées par script

**Décision** : `pnpm covers` (`scripts/fetch-show-covers.ts`) génère `scripts/config/show-covers.ts` (id de show → URL 300 px, 63 pochettes), à relancer quand `PODCAST_SHOWS` change.

**Pourquoi** : Aucun appel API ni secret côté navigateur ; le batch `/shows?ids=` est refusé en 403 ([LRN-008](../learnings/LRN-008.md)), donc un appel par show côté script.

**Alternatives considérées** : Appel Spotify à chaque chargement de la page, Edge Function dédiée.
