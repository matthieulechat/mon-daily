# BDR-007 — Ajout du serveur MCP Supabase project-scoped à mon-daily

**Décision** : Ajout du serveur MCP Supabase (`claude mcp add --scope project`) dans `.mcp.json` à la racine du repo, avec `project_ref` figé sur `mon-daily-paris`.

**Pourquoi** : Le dashboard Supabase suggère lui-même cette intégration pour manipuler la base directement depuis Claude Code (tables, migrations, logs) sans repasser par le navigateur. Le scope projet isole l'accès à `mon-daily-paris` uniquement, contrairement à un scope global qui exposerait tous les projets Supabase de l'organisation.

**Alternatives considérées** : Scope global/user (écarté, risque de croisement entre projets) ; ne pas l'ajouter et continuer via le dashboard web (écarté, plus lent pour les manipulations DB courantes).
