# BDR-040 — Animations CSS pures, pas de lib (GSAP écarté)

**Décision** : Toutes les animations de l'interface web sont en CSS (`@keyframes`, `transition`, token `--ease-snap`), avec un repli fondu seul sous `prefers-reduced-motion`

**Pourquoi** : Une cinquantaine de lignes suffisent, hors thread principal, sans poids de bundle (déjà > 500 ko)

**Alternatives considérées** : GSAP (~25 ko, utile seulement pour timelines/inertie du potard), `motion` (plus léger, mieux intégré à React)
