# BDR-041 — Bac ouvert dans la grille, sous la rangée de sa pile

| Décision                                                                                                                                                                                                  | Pourquoi                                                                                          | Alternatives considérées                                                       | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | ------ |
| Le bac est un enfant de la grille des piles (`col-span-full`), placé sur la ligne `floor(index / colonnes) + 2` (2 colonnes en mobile, 3 dès `sm`) ; `scrollIntoView({ block: "nearest" })` en complément | Le bac s'ouvrait sous la grille, hors fenêtre ; le seul défilement faisait trop descendre la page | Défilement seul (essayé, trop long), tiroir flottant, rangée de piles `sticky` | actif  |
