# BDR-013 — Actu = journaux du jour uniquement ; liste étendue à 55 shows

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Pourquoi                                                                                                                                                                                    | Alternatives considérées                                                                                                                        | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Seuls les journaux et flashs du jour sont classés `actu` dans `podcast-shows.ts` ; les émissions de débat/décryptage (C dans l'air, Code source, L'Heure du Monde, Les informés, 8h30 franceinfo, Sur le fil, La question info, Le Crayon) passent en `thematique`. Liste étendue de 28 à 55 shows (11 actu / 44 thématiques) après revue manuelle show par show via `docs/podcast-review.html`. Les shows à sujets durs (Affaires sensibles, Interception, Passages) sont acceptés sans filtre, la modération n'étant pas encore codée | Le classement initial (déduit de la colonne "Format" du ROADMAP) mettait en actu du contenu pas lié au jour même ; le pool thématique de 15 shows s'épuisait vite avec l'exclusion 14 jours | Garder le classement auto du ROADMAP ; ajouter des shows sans revoir les existants ; exclure les shows à sujets durs en attendant la modération | actif  |
