# BDR-004 — Identité visuelle "Bulletin Groove" retenue pour Mon Daily

**Décision** : Direction UI/branding figée sur "Bulletin Groove" (bleu `#2f93ff`, jaune `#ffd23f`, lime `#a3e635`, fond `#05080f`, Archivo Black/Archivo/JetBrains Mono) ; logo final = variante "O + texte" (disque vinyle, label jaune, icône radio centrée, "Mon Daily" en bas à gauche, inspiré de l'ancienne cover Daily Drive) ; description playlist = option H (métaphore face A/face B du vinyle).

**Pourquoi** : Synthèse itérative de 3 explorations (12 directions UI, 23 variantes de logo) convergeant vers l'esprit Spotify sombre + néon demandé par Matthieu, avec une signature vinyle/radio cohérente avec le concept "musique + actu quotidienne".

**Alternatives considérées** : 8 autres directions UI (Fréquence, Vinyle Nocturne, Flash Info, Onde Verte, Transmission, Aurore, Signal, Bulletin sans texte) ; 22 autres variantes de logo (A-N, P-V) ; texte circulaire ou en bandeau plutôt qu'en bas à gauche.
