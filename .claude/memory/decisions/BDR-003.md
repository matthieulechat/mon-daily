# BDR-003 — Souscription Premium personnelle du propriétaire plutôt que contournement

| Décision                                                                                                                           | Pourquoi                                                                                                                                                                                                                                                      | Alternatives considérées                                                                                                                                                                              | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Matthieu (propriétaire du compte développeur) souscrit lui-même un abonnement Spotify Premium pour débloquer la création de l'app. | Solution la plus simple et pérenne face à l'exigence Spotify (Premium obligatoire côté propriétaire depuis le 11 février 2026) — les alternatives impliquaient une dépendance externe, un recodage complet du provider, ou étaient fermées aux projets perso. | Un proche Premium crée l'app et ajoute Matthieu comme "authorized user" ; pivot vers Deezer en premier ; Extended Quota Mode (fermé aux perso) ; automatisation navigateur hors API (zone grise ToS). | actif  |
