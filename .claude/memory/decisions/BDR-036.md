# BDR-036 — Sources rangées en thèmes : piles (onglets) + bac, repliés par défaut

| Décision | Pourquoi | Alternatives considérées | Statut |
| -------- | -------- | ------------------------ | ------ |
| Chaque section (Actu, Thématiques) affiche une pile de pochettes colorée par thème (compteur + jauge) ; un clic ouvre son bac de disques, un second le referme, tout est fermé au chargement. Rangement purement visuel dans `web/src/lib/show-themes.ts` (la génération n'y touche pas), un id absent tombe dans « Autres » ; logique partagée dans `ThemeSection` | Une seule grande section de ~50 disques rendait l'interface dense ; les piles donnent une vue d'ensemble et le bac garde les disques tournants existants | Menus dépliants `<details>` (première version, jugée peu graphique) ; bac seul, sélecteur d'entrée type ampli, rack hi-fi (maquettes dans `docs/design/theme-categories-variants.html`) | actif |
