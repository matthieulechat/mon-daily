# BDR-033 — UI réglages : amp « home cinéma », sources en disques

**Décision** : Interface de réglages en façade d'ampli noir laqué et néon (afficheur de durée, potard à glisser, LED d'état, vinyle de fond avec bras de platine). Les podcasts sont des pochettes rondes : elles tournent quand la source est dans le mix, grisées et à l'arrêt quand elle est exclue.

**Pourquoi** : Prolonge l'identité « Bulletin Groove » (voir [BDR-004](BDR-004.md)) et rend l'état d'une source lisible d'un coup d'œil. Plus de 60 sources : la grille de disques passe mieux que des enceintes.

**Alternatives considérées** : Métal brossé, vintage hi-fi, système complet avec enceintes latérales, cônes d'enceinte ambre pour les podcasts.
