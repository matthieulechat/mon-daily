# BDR-002 — Storage Supabase dès la Phase 1 (skip JSON local)

| Décision                                                                                                                                                                                                                                                                                                                                                                    | Pourquoi                                                                                                                                                                                        | Alternatives considérées                                                                                        | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------ |
| Utiliser Supabase (Postgres) comme storage dès le MVP Phase 1, au lieu du JSON local (`data/store.json`) prévu par ARCHITECTURE.md pour l'Étape A. Le script `generate.ts` reste néanmoins lancé manuellement — pas de cron/Edge Function tout de suite (ça reste la Phase 3). Tables créées : `users`, `oauth_tokens` (RLS activé, accès uniquement via clé service role). | Baptiste a préféré éviter la double implémentation storage (JSON puis migration vers Supabase) — autant setup l'infra définitive dès le départ puisque le coût est nul (plan gratuit Supabase). | JSON local tel que documenté dans ARCHITECTURE.md (Étape A) ; SQLite (mentionné dans ROADMAP.md, jamais retenu) | actif  |
