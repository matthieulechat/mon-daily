# BDR-028 — France Culture rejoint `closestGroup` ; regex tolère la virgule

| Décision | Pourquoi | Alternatives considérées | Statut |
| -------- | -------- | ------------------------ | ------ |
| "Les journaux de France Culture" reçoit `closestGroup: journal-horaire` (podcast-shows.ts) et `TITLE_FR_LONG` accepte une virgule optionnelle après l'heure (`,?`) pour lire "JOURNAL DE 7H, du mercredi 30 septembre 2026" | Ce show publie plusieurs éditions par jour mais n'était dans aucun groupe : tous ses épisodes de moins de 2 jours restaient dans le pool et un journal ancien (7h) pouvait passer devant le plus récent (8h45). Sans le correctif du regex, l'heure du titre n'était pas lue (`null`) et le groupe n'aurait rien changé | `latestOnly` sur le show (ne compare pas avec les autres journaux horaires) | actif |
