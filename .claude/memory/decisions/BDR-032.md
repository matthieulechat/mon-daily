# BDR-032 — Code Node dans `scripts/`, `.env.local` racine partagé

**Décision** : `src/` déplacé dans `scripts/` (avec son `tsconfig.json`, scripts pnpm `login`/`generate`/`typecheck`/`test`). `web/` lit le `.env.local` racine (`envDir: ".."`) avec des `envPrefix` EXACTS (`VITE_`, `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`). Scripts `deploy:login` (login CLI + déploiement) et `deploy:edge` pour l'Edge Function

**Pourquoi** : Racine plus propre avec `web/`, `scripts/`, `supabase/` côte à côte ; un seul fichier d'env ; un préfixe `SUPABASE_` générique aurait embarqué la `service_role` dans le bundle navigateur ; `pnpm deploy` est une commande intégrée de pnpm, d'où `deploy:edge`

**Alternatives considérées** : Laisser `src/` à la racine ; `web/.env.local` séparé avec clés `VITE_*` dupliquées
