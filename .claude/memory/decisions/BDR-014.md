# BDR-014 — Auteur du projet : Matthieu LECHAT (plus Baptiste)

**Décision** : L'attribution dans les README (footer « Made with ❤️ by »), les docs (`docs/ROADMAP.md`, `docs/PLAYLIST_GENERATION.md`) et les commentaires de code est « Matthieu LECHAT » / « Matthieu ». Le lien GitHub du clone et du footer suit le remote git : `github.com/matthieulechat/mon-daily`. Les mentions de « Baptiste » dans `.claude/memory` (28 au 2026-09-23) sont laissées telles quelles en attendant une décision distincte

**Pourquoi** : Matthieu est propriétaire du repo (remote `matthieulechat`) et du compte développeur Spotify (cf. `docs/PRD.md`) ; l'ancien nom venait du footer par défaut du skill `readme-writer`

**Alternatives considérées** : Remplacer en bloc dans `.claude/memory` (écarté : [ZBLK-003](../archive/blockers/ZBLK-003.md) distingue les deux personnes, le sens deviendrait incohérent) ; garder le handle `baptistelechat` dans les liens (écarté : le remote git pointe vers `matthieulechat`)
