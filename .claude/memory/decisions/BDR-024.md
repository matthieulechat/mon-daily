# BDR-024 — Journaux horaires : filtre inter-shows via `closestGroup`

| Décision | Pourquoi | Alternatives considérées | Statut |
| -------- | -------- | ------------------------ | ------ |
| Les shows « Le journal de XXhXX » (6h à 19h, France Inter/France Culture) portent un `closestGroup` commun ; après collecte de tous les shows, `keepClosestByGroup` (podcast-source.ts) ne garde que l'épisode dont l'heure lue dans le titre est la plus proche de l'heure de génération, par catégorie. Les shows restent dans la config, seuls leurs épisodes sont filtrés. | Chaque édition est un show Spotify distinct : `latestOnly` (par show) ne peut pas comparer 07h00 et 18h00 entre eux. Le filtre doit agir entre shows pour garantir une actu fraîche. | `latestOnly` sur chaque show (ne compare pas entre shows) ; supprimer les éditions superflues de la config (perte de flexibilité, refusé par Baptiste). | actif |
