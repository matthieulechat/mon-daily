# BDR-016 — Historique des mix supprimé, pool de podcasts assez large

| Décision                                                                                                                                                                                                                                                                                                          | Pourquoi                                                                                                                                                                                                                                                                    | Alternatives considérées                                                                                                                                             | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Plus aucun historique des mix : `saveHistory`, `getRecentShowIds` et `resolveInternalUserId` retirés de `supabase-storage.ts`, interface `Storage` réduite à `getTokens`/`saveTokens`, table Supabase `playlist_history` supprimée (migration `drop_playlist_history`, 3 lignes de test), docs et README nettoyés | Avec 55 shows et des dizaines d'épisodes éligibles, retomber sur le même podcast deux jours de suite est peu probable. L'historique n'était plus lu depuis le retrait de la rotation ([BDR-015](../decisions/BDR-015.md)) : il ne restait qu'une écriture sans consommateur | Garder l'écriture seule pour un futur « historique visible » en Phase 6 (écarté, récupérable via git) ; rotation légère de 1 à 2 jours (écarté, la simplicité prime) | actif  |
