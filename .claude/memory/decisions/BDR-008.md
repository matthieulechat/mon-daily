# BDR-008 — Liste des médias étendue à 28 shows avant validation de LRN-006 ; préférences et modération repoussées

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Alternatives considérées                                                                                                                                                                                                                                   | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| La liste des médias (Phase 2, `docs/ROADMAP.md`) passe de 3 shows pilotes à 28 shows Spotify natifs (25 fournis par Baptiste, résolus via l'API `GET /shows/{id}?market=FR` pour confirmer existence + nom réel), **avant** que le risque [LRN-006](../learnings/LRN-006.md) (playabilité des épisodes insérés dans une playlist) ait été testé manuellement. Le filtrage par préférence (durée max, fréquence de publication) et la modération par mots-clés sur le titre (sujets retenus : guerre/conflits armés, sexualité, violence/faits divers) sont documentés comme tâches futures dans le roadmap, explicitement dépriorisés pour le moment. | [BDR-005](BDR-005.md) prévoyait de valider les 3 pilotes avant d'élargir, mais Baptiste a fourni la liste complète directement et n'a pas le temps de faire le test manuel maintenant — élargir la liste dans la documentation ne coûte rien (aucun code podcast n'existe encore dans `src/`, le risque s'applique de la même façon à 3 ou 28 shows). Les préférences/modération demandent un vrai design (types, stockage, moteur) qui n'a pas de valeur tant que le mixer n'existe pas. | Attendre la validation LRN-006 avant d'élargir la liste (écarté, Baptiste veut la liste complète dès maintenant) ; implémenter dès maintenant le moteur de préférences/modération (écarté explicitement par Baptiste : "pas une priorité pour le moment"). | actif  |
