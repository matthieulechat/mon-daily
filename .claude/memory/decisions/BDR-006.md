# BDR-006 — Bascule du projet Supabase de Dublin vers Paris

| Décision                                                                                                                                                                                                                                                        | Pourquoi                                                                                                                                                                                                                                       | Alternatives considérées                                                                                                                                                                                                                                            | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Recréation du projet Supabase en région `eu-west-3` (Paris), nommé `mon-daily-paris`, avec les mêmes tables `users`/`oauth_tokens` (RLS activé, aucune policy). L'ancien projet `mon-daily` (Dublin, `eu-west-1`), vide, est mis en pause et conservé tel quel. | Préférence de Baptiste pour héberger les données en France. Le projet n'avait jamais servi (aucune donnée), donc recréer ne coûte rien. Supabase ne permet de toute façon pas de changer la région d'un projet existant (voir aussi GLRN-285). | Garder Dublin (latence négligeable pour un script perso lancé 1x/jour — écarté, choix explicite de Baptiste) ; migrer en place (impossible techniquement) ; supprimer l'ancien projet avant de recréer (impossible, aucun outil MCP pour ça — voir aussi GLRN-286). | actif  |
