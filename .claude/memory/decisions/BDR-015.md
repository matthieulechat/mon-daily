# BDR-015 — Fraîcheur podcast par catégorie ; rotation thématique retirée

**Décision** : Âge max d'un épisode par catégorie (`EPISODE_MAX_AGE_DAYS` dans `podcast-source.ts`) : actu 2 jours, thématique 3 jours. Rotation de 14 jours des shows thématiques retirée de `generate.ts` : tous les shows thématiques sont éligibles chaque jour, seule la fraîcheur filtre. Retrait complet de la rotation prévu plus tard

**Pourquoi** : Les actus périment vite, les thématiques tolèrent plus. La rotation épuisait le pool (tension déjà notée dans `docs/PLAYLIST_GENERATION.md`) et Matthieu prévoit de la retirer entièrement

**Alternatives considérées** : Actu 1 jour (écarté, cf. [LRN-020](../learnings/LRN-020.md) : seuls les épisodes du jour passeraient) ; thématique 7 jours ; rotation conservée à 7 jours
