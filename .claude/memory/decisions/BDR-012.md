# BDR-012 — Podcasts : catégorisation actu/thématique + gabarit fixe 4+4

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Pourquoi                                                                                                                                                                                                              | Alternatives considérées                                                                                                                                                                                                                                                       | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| Shows catégorisés manuellement `actu`/`thematique` dans `podcast-shows.ts`. Gabarit fixe : 2 actus en ouverture (avant toute musique), puis alternance actu/thématique toutes les 4 musiques jusqu'à 4 actus + 4 thématiques placées ; au-delà, musique seule jusqu'à la coupe durée. Tirage au sort dans chaque pool éligible (pas un ordre fixe), fallback croisé si un pool est trop court. Playlist plafonnée à 4h par troncature durée en fin de pipeline | Aucun signal de popularité exploitable côté API Spotify (ni sur les shows, ni dans l'historique d'écoute) ; plusieurs itérations avec Baptiste ont convergé sur ce compromis entre fraîcheur, variété et budget temps | Ordre fixe par priorité de liste (rejeté, pas assez varié) ; nombre de thématiques illimité tant que 4h non atteint (rejeté, remplacé par un plafond fixe de 4) ; rotation par exclusion dure sur 14 jours sans plafond de tirage (rejeté, épuisait le pool en quelques jours) | actif  |
