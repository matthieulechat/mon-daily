# BDR-042 — Bouton Enregistrer : confirmation intégrée, durée mini 0,9 s

**Décision** : `SaveButton` : spinner pendant la sauvegarde, flash vert avec coche tracée, retour à l'état grisé ; `save()` du store attend au moins 900 ms

**Pourquoi** : Remplace le texte « Enregistré ✓ » à gauche ; la sauvegarde est quasi instantanée donc l'état « en cours » clignotait

**Alternatives considérées** : Garder le texte à gauche, animer seulement la LED
