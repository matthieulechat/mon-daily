# BDR-019 — HugoDécrypte : actu/thématique croisant titre et description

| Décision                                                                                                                                                                                                                                                                                                                      | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                         | Alternatives considérées                                                                                                                                                           | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `detectEpisodeCategory` étendu avec une règle dédiée au show id `6y1PloEyNsCNJH9vHias4T` (HugoDécrypte) : un épisode compte `actu` si son titre finit par une date `(xx/xx)` OU commence par `"(Pop)"`, OU si sa description contient la phrase standard "résumé de l'actualité du jour"/"...culturelle" — sinon `thematique` | Baptiste a signalé des épisodes mal classés (actu du jour sans date en suffixe de titre, ex. "Le Royaume-Uni vit-il ses dernières heures ?"). Vérification API a confirmé que la description contient un texte standard fiable pour ces deux formats, mais certains épisodes `(Pop)` ont leur description tronquée par l'endpoint liste Spotify (le passage standard manque) — d'où le croisement en OR plutôt qu'un seul signal | Basculer entièrement sur la description (rejeté, cassait le cas des `(Pop)` à description tronquée) ; garder le titre seul (rejeté, ratait les actus du jour sans date en suffixe) | actif  |
