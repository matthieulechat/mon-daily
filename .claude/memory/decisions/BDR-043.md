# BDR-043 — Podcast trop long : repiocher plus court, pas de comblage musique

**Décision** : `buildMix` connaît le budget de durée (réglage + jingle) : un épisode qui ne tient pas est écarté, un plus court est tiré dans la même file puis dans l'autre catégorie ; si rien ne tient, l'emplacement reste vide et la musique ne comble pas

**Pourquoi** : Le `break` de `truncateToDuration` coupait toute la fin de la playlist (208 min au lieu de 240) dès qu'un podcast long ne rentrait pas ; le gabarit musique/podcast doit rester intact

**Alternatives considérées** : `continue` dans `truncateToDuration` : comble la fin avec de la musique, écarté (demande explicite de ne pas combler)
