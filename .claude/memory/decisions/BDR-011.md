# BDR-011 — Mix musique : répétition volontaire, découvertes retirées

**Décision** : Le mix musique repose uniquement sur les top tracks Spotify (`time_range=short_term`), dédupliqués, sans mécanisme de découverte

**Pourquoi** : Baptiste veut retrouver ses musiques les plus écoutées tous les jours ; la répétition est voulue, pas un défaut à corriger

**Alternatives considérées** : Découverte par recherche de genre (`discoverTracksForGenres`, code supprimé, récupérable via git) ; enrichissement via 2 playlists éditoriales Spotify (bloqué côté API, cf. [LRN-015](../learnings/LRN-015.md))
