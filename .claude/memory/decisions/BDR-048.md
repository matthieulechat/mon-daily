# BDR-048 — 429 du 2ᵉ compte au cron : pas de pause ajoutée

**Décision** : On ne modifie pas l'enchaînement des deux comptes dans `generate-daily` malgré les podcasts ignorés sur 429 chez le compte traité en second (11 le 09/10, 5 le 05/10)

**Pourquoi** : Sur les 5 matins du 05 au 09/10, trois n'ont aucun 429 avec exactement le même enchaînement. Le 05/10 s'explique par la sortie du blocage de la veille ([ZBLK-024](../archive/blockers/ZBLK-024.md)) ; le 09/10 coïncide avec un 502 Spotify dans le même run. Le mix est sorti correct les deux fois (165 épisodes thématiques dans le pool le 09/10). À revoir si les 429 deviennent fréquents ou si un mix sort visiblement appauvri

**Alternatives considérées** : Pause entre les deux comptes (code posé sans cause établie) ; augmenter le nombre de tentatives
